# 桌面捏捏 E2E 测试方案 v0.1

日期：2026-09-20。对应实施方案 v0.1。状态：已执行部分自动验证和 UI 冒烟；完整 E2E 尚未通过。详见 ../验证记录.md。

## 测试边界

目标是用户在真实 macOS 桌面与真实 Codex 任务等待期间完成“选物体 → 捏碎并听到声音 → 换物体 → 得知任务完成”。浏览器交互样本不等于桌面 E2E，模拟状态不等于真实 Codex 联动。

环境记录包括机器型号、macOS 和 Codex 版本、应用 commit、素材版本、显示器与缩放比例、音频输出设备。成本为本地 0 元；真实状态验证优先观察用户本来要运行的任务，新增付费任务需先明确预算。

## 核心用例

下表为完整验收计划，不能因为部分行为测试通过而将整项标记通过。当前执行边界见 ../验证记录.md。证据保存在被 Git 忽略的 artifacts/ 下：录屏、输入与破裂事件时序、状态事件摘要、性能测量及人工意见，不保存提示词正文。测试后退出应用，恢复音量、窗口位置与临时配置。

| ID | 覆盖范围 | 前置与输入 | 步骤 | 预期行为及证据 | 计划时长 |
|---|---|---|---|---|---|
| E01 | 点按、位置、破裂累计 | 完整草莓、有线或内置音频 | 连点顶部与侧面，捏穿后继续点 | 点击处先变形再开裂，旧裂纹保留；软芯声与完整破壳声有区别，录屏并记录事件 | 2分钟 |
| E02 | 长按、松开与取消 | 三种材质、完整状态 | 按住后移出物体再松开；切换窗口 | 不发生卡住持续加力；仅软体回弹，破壳不自动复原；释放事件记录 | 3分钟 |
| E03 | 音效、静音 | 音频素材可用 | 10次捏压，静音，再调整音量 | 无机械性固定重复；静音立即生效；连续点击无削波或失控叠加；实际试听 | 3分钟 |
| E04 | 换物与重置 | 三种样本 | 捏碎后重置，再切到其他材质 | 碎屑与旧声音不会串到新物体；每种材质破坏方式可区分 | 2分钟 |
| E05 | 桌面窗口 | 真正桌面应用、底层编辑器 | 点击透明区域、捏物、拖把手、返回输入 | 空白可穿透；物体可点；不触发底层误点击；不主动抢输入焦点；录屏 | 5分钟 |
| E06 | 模拟状态契约 | 固定事件夹具 | 工作、等待操作、完成、失败、断连，插入重复及迟到事件 | 不误报完成、不重复提醒；旧任务事件不覆盖新任务；断连显示未知 | 3分钟 |
| E07 | 真实 Codex 联动 | 本机入口已验证、用户实际任务 | 用户发起任务，在等待中捏，观察正常结束与中断 | 每个状态有对应真实事件；完成不强制终止当前捏压；中断不冒充成功；记录任务标识与时间 | 随任务耗时 |
| E08 | 隔离与故障 | 状态桥接、两项实际或回放任务 | 桥接断开、另一个任务完成、重启桌宠 | 当前绑定任务不串状态；捏捏仍可使用；失败不阻塞 Codex，不发起模型调用 | 5分钟 |
| E09 | 性能与设备 | 两种音频设备、多显示器如可用 | 连捏、静置、切屏与缩放，持续10分钟 | 记录反馈 P95、帧率、CPU及内存趋势；目标有线反馈<50ms、交互60fps；蓝牙单独报告 | 10分钟 |
| E10 | 手感人工验收 | 三种样本、耳机 | Lexie 每种连续体验约1分钟 | 分别评价受力感、脆感、声画一致及是否愿意继续捏；明确保留、调整、否决 | 5分钟 |

## 实施时的测试顺序

先写破坏状态、松开取消、音频事件以及任务状态映射的行为测试，再实现相关逻辑。通过本地交互与模拟事件检查后验证桌面窗口，最后进行真实 Codex 联动与手感验收。

测试 oracle 来自实施方案中的可见行为，而非复制实现常量；真实音轨、桌面焦点及主观手感不能用 Mock 通过代替。

## 发布门禁

- E01–E06、E08–E10 通过才可交付独立桌面体验版；手感需用户明确认可。
- E07 通过且状态入口有真实证据后，才能声称与 Codex 联动完成。
- 每项记录通过、失败、跳过或未验证。当前已执行项与剩余边界见 ../验证记录.md。
- 不支持的全屏、Space 或音频设备行为须具体说明；不得将未知写成支持。
