# 两秒炸掉

> 2026-09-27 开源准备更新：当前短哼已替换为 `app/web/anger-voice.mjs` 的原创 0.48 秒电子合成，旧的人声 PCM 已从当前源码移除。下文的录音选段及试听是历史记录，不再描述当前发行素材。旧 Git 历史仍需与首次公开快照隔离。

已确认方案：四种水果均支持持续按住 2 秒后炸开，壳片向外飞散，只留下可揉拉的无壳软芯；显示“我炸了 😡”，伴随轻柔可爱的生气短音。

## 交互

- 点按和不足两秒的长按仍渐进碎裂；松手保留当前损坏，但清空本次蓄力时间，多次短按不累计。
- 连续按满 2 秒，一次性起爆；接近阈值时轻抖。按压阈值按实际连续时间判断，不因绘制短暂停顿而推迟。
- 壳片从起爆瞬间的当前纹理切出，约 0.72 秒内向外飞散、旋转、缩小并淡出。四种水果各有独立透明软芯图，不保留壳、果蒂或叶片。
- 起爆后同一次按压不会把软芯继续压扁；松开，再捏或拖动即可揉拉。已炸过的软芯不重复起爆；重置、换物或任务完成后的复原会恢复完整状态。
- 顶部文字为“我炸了 😡”，停留 2 秒，再用 0.4 秒淡出。任务完成提醒在按住或生气气泡显示期间排队，之后继续原有复原、外缘绿光、轻浮与 biu。
- 生气音为用户选定的声之浪潮“女孩1”样音约 3.512–5.162 秒片段，按用户确认的两秒试听去掉末尾 0.35 秒，保留 1.65 秒，保留原音高和速度。播放时停止残余碎裂声，遵守原音量和静音设置；渐进碎裂 ASMR 和完成 biu 保持原样。

## 素材和复建

- 四张纯软芯使用内置 ImageGen 的参考图编辑模式生成，参考各水果第 38 帧，以保持灯光、颜色和质感；使用生成的真实 alpha。
- 源文件已复制到本项目 `artifacts/anger-burst/{lychee,peach,orange,mangosteen}-core.png`；完整提示词在同目录各水果的 `*-prompt.txt`。
- 打包器内嵌当前水果的五页序列及一张软芯，只解码当前水果；软芯加载失败会阻止进入交互，避免爆炸后空白。
- 此次没有调用即梦或重生成视频。图片、试听 WAV、验证页、测试日志均在忽略目录 `artifacts/anger-burst/`；换机器重建需复制该目录与原透明序列素材。
