# 小红书展示视频 · 第一版

目标：约 24 秒竖屏解压展示，以真实碎裂、炸开和软芯揉拉为主体，少量字幕，保留近距离捏捏声，不加背景音乐或配音。

成片：`artifacts/xiaohongshu/捏一会儿-小红书竖屏-v1.mp4`。封面：同目录 `封面.png`。1080×1920、30 fps，H.264 / AAC、48 kHz 双声道。

## 剪辑内容

- 0–7 秒：荔枝由完整逐步捏碎，字幕“把压力，捏碎一点”。
- 7–10.5 秒：笑脸烤年糕渐碎。
- 10.5–14.5 秒：大福按住两秒炸开，“我炸了”和已选定的“哼”。
- 14.5–18.5 秒：豆沙软芯揉拉，切用已选定的实录软泥音。
- 18.5–24 秒：演示 Codex 回复后复原、轮廓绿光、轻浮与 biu。

直接复用项目状态机、透明图集、软芯、渲染器、音效，在离线 Canvas 中按脚本操作渲染；这是配有展示字幕和演示通知的交互剪辑，不是原生桌面录屏。没有导入真实任务标题，也没有再次提交付费视频生成。

## 复现

运行 `node scripts/render-social-video.mjs`，输出静音视频、同期 PCM、分阶段 PNG 及状态/音效时间表。脚本使用本机 Codex 运行时提供的 `@napi-rs/canvas`，不新增应用依赖。

然后将静音视频与 `audio.s16le`（44100 Hz、单声道、16 bit little-endian）通过 ffmpeg 合成；响度目标 -20 LUFS、真峰值上限 -2 dBTP，最后半秒音频淡出，启用 faststart。

素材与生成输出保持在 gitignore 的 artifacts 下。没有发布到小红书。

## 本次验收

最终视频 24.000 秒、720 帧、约 3.7 MB；完整解码无错误。成片实测综合响度 -21.05 LUFS、真峰值 -5.14 dBTP。检查荔枝、年糕、爆炸、软芯与复原关键画面，修正了揉拉特写横向超出画面的问题。爆炸声触发于 12.867 秒，完成音触发于 18.5 秒；没有重新生成或更换用户选定音色。审美与听感仍以用户观看成片反馈为准。
