## 遇到的问题与处理

1. 本机 Swift 编译器/SDK 版本不兼容，首次编译失败。改用 Objective-C 编译同一 AppKit/WebKit 窗口层，未修改本机工具链。

3. 项目目录给 `.app` 附加 Finder/File Provider 元数据，导致签名/校验失败。改成临时目录构建和签名，产出 ZIP，安装到用户 Applications 后校验通过。
