# 透明交互荔枝

本版使用已验收的 Seedance 2.5 荔枝样片，移除灰色摄影背景，鼠标驱动透明帧序列。完整果壳、开裂过程与末尾软泥均来自同一条视频。碎裂路径固定；鼠标决定推进多少，不能改变裂纹位置。末帧接入原来的网格形变，支持按扁、揉拉和松手回拢。

## 素材准备

不重新调用生成模型，不产生新的积分消耗。原视频和透明图集作为生成产物保存在被忽略的 `artifacts/`，应用包内嵌图集，运行时不依赖该目录。全新检出必须另外取得已验收视频；素材缺失时构建明确报错，不静默退回旧画面。

```sh
python3 -m venv --system-site-packages .venv
# 本机 Python 已有 numpy、Pillow、opencv-python、scipy；其他环境需要安装这些离线处理依赖。
ffmpeg -y -i artifacts/lychee-video/output/荔枝按压-Seedance2.5.mp4 -vf fps=24 artifacts/lychee-video/frame-%03d.png
.venv/bin/python scripts/prepare-lychee-sequence.py
node scripts/bundle.mjs
bash scripts/build.sh
```

80 帧：源第 1 帧及 43–121 帧，略过片头静止展示。每帧 448×448，五张 4×4 RGBA 图集。GrabCut 用红壳颜色与主体内部作为种子，底部接触台面的边界用手工关键帧约束；去除投影和散落的桌面碎屑。`alpha-review.jpg` 用深色、浅色和棋盘背景核对边缘。

透明指背景 alpha；内芯保留样片已经呈现的半透、反光质感。单一灰背景视频无法还原真实透射率，因此白色内芯不会随着桌面内容折射或变色。

## 交互合同

- 单次按下立即推进 2 帧；持续按住每秒推进 18 帧。松手冻结破壳进度，换一个才复原。
- 点击与每 0.24 秒的持续受力使用未修改的 `rind` 音色；不播放原视频音轨，不触发旧版长按爆裂音。
- 末帧固定为同一张软泥纹理，之后可揉拉。静止长按不循环播碎裂声；揉拉声由实际移动触发。
- 真实 alpha 决定命中和原生窗口穿透区域。加载成功前不推进荔枝。
- 原版模型留作其他材质与既有回归测试；实际应用创建 `InteractiveSqueezeModel`，使用序列渲染器。

验证结果随实现完成后记录在 `docs/验证记录.md`。
